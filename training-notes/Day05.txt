OOPs - is a way of organizing code into objects and classes, which makes it more modular and easier to maintain.

1. Inheritance: It allows one class to acquire properties and methods from another class. It uses the keyword `extend`.
    ex: class Animal{       
    }
    class Dog extends Animal{
    }

2. Polymorphism: It allows methods with the same name to have different implementation. This is where a child class provides it owns implementation of a parent class method.
    ex: class Animal{
        constructor(name){
            this.name = name;
        }
        sound(){
            return `${this.name} makes a sound`;
        }
    }
    class Dog extends Animal{
        sound(){
            return `dog barks...`
        }
    }

3. Encapsulation: It refers to wrapping methods and data bundled inside a class restricting direct access to certain details. It helps protect data from unauthorized access and modification. It is achieved by using private(#) fields and methods.
    ex: class Account{
        #balance = 0;
        deposit(amount){
            this.#balance += amount;
        }
        getBalance(){
            return this.#balance;
        }
    }

4. Abstraction: It refers to hiding complex implementation details and exposing only the essential features of an object.
    ex: class CoffeMachine {
        #waterTemperature = 90;
        #boilWater()
        {
        return `Boiling water to ${this.#waterTemperature} degrees.`;
     }
    #grindBeans() 
    {
       return "Grinding beans.";
     }
}
