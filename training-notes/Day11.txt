TypeScript
-----------------------------------
- Primitives (Number, String, Boolean): Stores actual value directly.
- Reference Type: Stores reference to a value

Types, Annotation & Inference:
    1) Explict Typing: You explicitly declare type of a variable.
        ex-
            greet: string = "Hello"
            userName: number = 42'
            
            function greet(name: string) : string{
                return `Hello ${name}`
            }
    
    2) Type Inference: TS can automatically determine the type of a variable based on initial value;
            ex-
                let username = "aryan"
                {TypeScript infers 'String'}

# Any: When TS cant infer Types, it falls back to 'any' type

# Unknown: It is a safe counterpart for any, use when unsure of tupe safety, while still allowing flexibility.

# Never: Used for functions that never return. (Used where we always had to throw an error or something)

# Undefined & Null:->
 - Undefined is used when variable has been declared but not assigned a value.
 - Explicit assignment that represents no value or no object.


Tuples: We define the data type for each element.
        ex: let arr: [string, number] = ["Tada",23];

Enums: It represents a group of constants, each property have some values. They are predefined sets which are used in some coding paradigms.
            enum userRole {
                ADMIN = "admin",
                GUEST = "guest",
                SUPER = "super"
            } 

Interfaces: They are only applied to object types.
            interface User{
                name: string,
                email: string,
                gender?: string,
                password: string
            }
    
    gender?: string (means that it is optional)

    #Extend: Extend Keyword is used to showcase/inherit properties between interfaces.
            
            interface Admin Extends User{
                salary: number
            }
    
    #Intersection (&): Represented by the help of & keyword, combines multiple types into one.

    #InterFace Merging: When two interfaces have the same name, both the interfaces have all the properties combined.
            ex:- 
                interface ABC{
                    name: string
                }
                interface ABC{
                    age: number
                }
