# Wipro_Training

### Day1

1. String Operations:
   -> .length(): to get the length of the string.
   -> .toUpperCase(): converts the char's/string to uppercase.
   -> .toLowerCase(): converts the char's/string to lowercase.
   -> .substring(start, end): used to extract part of a String.

2. Mathematical Operations:
   -> + (addition)
   -> - (subtraction)
   -> \* (multiplication)
   -> / (division)
   -> % (modulo)

3. Logical / Comparison Operations:
   -> > (greater than)
   -> < (less than)
   -> == (equals to)
   -> === (strict equal)
   -> != (not equal to)
   -> >= (greater than or equal to)
   -> <= (less than or equal to)

4. Var - let - const:
   -> var: function scoped, gets updated outside of block.
   -> let: block scoped, stays inside block.
   -> const: Once declared cant be changed.

5. Arrays:
   -> Can store mixed types (numbers, string, boolean, etc.)
   -> Access using index

6. Loops:
   -> For Loop: Used when index is needed.
   -> While Loop: Runs until a condition becomes false.
   -> forEach(): Used for arrays only, used for iteration only.

7. Conditional:
   -> if/else: Executes block based on condition.
   -> switch cases: Uses strick comparison, break is required.

8. Web Basics:
   - client Server Architecture:
     Client sends request, Server process request and sends response.
   - URL (Uniform Resource Locator) {Domain + Endpoint}
   - Domain (main address, exmaple.com)
   - EndPoint (specific path, /api/user)
   - `When a client sends request 3 things can happen. Processing: Request is being handled, Succesful: Data received correctly, Failed: Error occured`

9. DOM Selection:
   - getElementById()
   - getElementByClassName()
   - getElementByTagName()

10. Logical Operators:
    - && (AND)
    - || (OR)
    - ! (NOT)

11. Functions:
    - Reusable blocks of code
    - Can return values using return

### Day2

1. Template Literals:
   - Use backticks ``
   - embed variables using ${}
   - cleaner than string concatenation

2. Arrow Functions:
   - shorter syntax for functions.
   - (x,y) => x + y

3. Array Methods:
    - forEach(): Just loops, no return.
    - map(): transforms elements, returns new array of same length.
    - filter(): selects elements, returns a new array.
    - find(): It returns the first match it finds.
    - push(): Add at end.
    - pop(): Remove from end.
    - unshift(): Add at front.
    - shift(): Remove from front.
    - splice(): Add/remove elements, modifies original array.
    -slice(): Copies part of array, Does not modify original array.
    - indexOf(): Returns index of element (-1 if not found).
    -includes(): Returns true/false
    - Array Acess: arr[i], arr.length, arr[arr.length - 1]

4. Math Functions:
    - Math.random() -> Returns value between 0 and 1.
    - Math.floor() -> Rounds down to the lowest integer.
    - Math.ceil() -> Rounds down to the highest integer value.
    - Math.round() -> Rounds up the values to the nearest whole integer.

5. Type Conversion:
    - parseInt(): Converts, string -> integer.
    - parseFloat(): Converts, string -> float.
