### Day2

1. Template Literals:
   - Use backticks ``
   - embed variables using ${}
   - cleaner than string concatenation

2. Arrow Functions:
   - shorter syntax for functions.
   - (x,y) => x + y

3. Array Methods:
    - forEach(): Just loops, no return.
    - map(): transforms elements, returns new array of same length.
    - filter(): selects elements, returns a new array.
    - find(): It returns the first match it finds.
    - push(): Add at end.
    - pop(): Remove from end.
    - unshift(): Add at front.
    - shift(): Remove from front.
    - splice(): Add/remove elements, modifies original array.
    -slice(): Copies part of array, Does not modify original array.
    - indexOf(): Returns index of element (-1 if not found).
    -includes(): Returns true/false
    - Array Acess: arr[i], arr.length, arr[arr.length - 1]

4. Math Functions:
    - Math.random() -> Returns value between 0 and 1.
    - Math.floor() -> Rounds down to the lowest integer.
    - Math.ceil() -> Rounds down to the highest integer value.
    - Math.round() -> Rounds up the values to the nearest whole integer.

5. Type Conversion:
    - parseInt(): Converts, string -> integer.
    - parseFloat(): Converts, string -> float.
